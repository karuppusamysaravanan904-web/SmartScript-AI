# HANDWRITE AI
### Extreme Bad-Handwriting Digitizing & Multilingual Document Conversion Platform
**Problem Statement Reference: HNX26EPS04**

A complete, production-ready full-stack platform built to digitize extreme bad handwriting, multi-script Indian language documents, and structured tables into clean editable text, Word documents (.docx), PDFs, and PowerPoint presentations (.pptx).

- **Backend (FastAPI):** `http://127.0.0.1:8000` (Docs: `http://127.0.0.1:8000/docs`)
- **Frontend (Vite + React):** `http://127.0.0.1:5173`
